# FindIt

## Présentation du projet

FindIt est une application web de gestion des objets perdus et trouvés.

Elle permet aux utilisateurs de publier des déclarations concernant des objets perdus ou trouvés, de consulter les annonces et de faire des réclamations pour récupérer leurs objets.

## Fonctionnalités principales

- Création de comptes utilisateurs et authentification.
- Publication d'annonces d'objets perdus ou trouvés.
- Consultation et recherche des objets.
- Classement des objets par catégorie.
- Localisation des objets.
- Gestion des réclamations.
- Gestion des rôles et des autorisations.

## Technologies utilisées

- Node.js
- Express.js
- MySQL
- Sequelize
- Postman
- GitHub
